Production architecture roadmap

Required before real ministry use

1. Secure identity & database

Use a managed authentication provider, agency membership records, least-privilege database grants and row-level security. Enforce access on the server/database, not only in the interface.

2. Offline synchronization

Use a durable local outbox, idempotency keys, retry/backoff, conflict handling, attachment upload queue and clear sync status. Minimize sensitive local storage.

3. Operations & assurance

Configure backups, tested restores, monitoring, incident response, retention, staff training, accessibility checks and independent security review.

This file does not include a live cloud backend, real authentication, SMS delivery, production AI, real mapping, or a security certification. Do not publish secret keys in client-side code.
